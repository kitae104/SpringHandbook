홈 수업 핵심 용어 @Id

JPA 기본 매핑

@Id

Entity에서 각 행을 유일하게 식별하는 기본 키 필드를 지정하는 JPA 애너테이션입니다.

용어 핵심 약 5분

정확한 뜻

@Id는 JPA가 Entity의 동일성을 판단할 식별자 필드를 지정합니다. 모든 Entity에는 반드시 식별자가 있어야 하며 일반적으로 DB의 PRIMARY KEY 열과 매핑됩니다.

필드 접근 방식에서는 필드에, 프로퍼티 접근 방식에서는 getter에 붙입니다. 한 Entity 안에서 접근 방식을 섞지 않는 것이 좋으며 복합 키는 @EmbeddedId 또는 @IdClass로 별도 구성합니다.

실제로 동작하는 순서

01 Entity 등록

JPA가 @Id가 붙은 속성을 식별자 매핑으로 해석합니다.

02 영속화

식별자 값을 기준으로 새 Entity인지 기존 Entity인지 판단합니다.

03 조회와 동일성

영속성 컨텍스트는 Entity 타입과 식별자 조합으로 관리 객체를 구분합니다.

비슷한 용어와 구분하기

@Id

Entity 식별자와 DB 기본 키를 매핑합니다.

@EmbeddedId

여러 값을 하나의 임베디드 객체로 묶어 복합 키로 사용합니다.

자연 키

업무 의미가 있는 값이며 변경 가능성을 고려해야 합니다.

대리 키

업무 의미 없이 식별만 담당하는 Long 등의 생성 키로 흔히 사용합니다.

대리 키를 사용하는 Entity

@Entity
class Course {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
}

수업에서 확인할 포인트

  • 식별자 타입은 null을 표현할 수 있는 Long 같은 래퍼 타입을 많이 사용합니다.
  • 영속화된 Entity의 식별자를 임의로 변경하면 안 됩니다.
  • equals와 hashCode에 생성 전 null 식별자를 사용할 때 컬렉션 동작을 주의해야 합니다.

함께 읽을 주제

EntityDB 테이블과 매핑되는 도메인 객체이며 JPA가 영속성 컨텍스트에서 상태 변화를 추적합니다.JPA자바 객체와 관계형 DB 테이블을 매핑하고 영속성 컨텍스트를 통해 변경 감지, 지연 로딩, 트랜잭션 동작을 제공합니다.JPA 연관관계와 매핑1:1, 1:N, N:1, N:M 관계와 연관관계의 주인, Fetch Type, Cascade, Orphan Removal, N+1 문제를 정리합니다.
