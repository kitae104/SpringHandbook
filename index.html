Learning Map

먼저 잡아야 할 큰 그림

요청 흐름

브라우저가 HTTP 요청을 보내면 Controller가 받고, Service가 규칙을 처리하고, Repository가 DB와 대화합니다.

객체 관리

Spring은 객체를 Bean으로 등록하고 IoC/DI로 필요한 곳에 자동으로 연결합니다.

데이터 처리

DTO는 요청/응답 데이터, Entity는 DB 테이블과 가까운 데이터 모델로 구분합니다.

운영 준비

보안, 로깅, 설정, 문서화, 배포 자동화는 실무형 프로젝트로 가기 위한 기본기입니다.

Part 1

Spring 기초

01

Spring Framework

자바 애플리케이션을 더 구조적으로 만들기 위한 기반 프레임워크입니다. 객체 생성, 의존성 연결, 웹 요청 처리, DB 연동 같은 반복 작업을 도와줍니다.

@Component
public class HelloService {
    public String message() {
        return "Hello Spring";
    }
}

핵심은 “객체를 직접 만들고 연결하는 부담을 Spring에게 맡긴다”는 점입니다.

02

Spring Boot

Spring을 더 쉽게 시작하도록 만든 도구입니다. 서버 실행, 기본 설정, 의존성 조합을 자동화해서 수업과 프로젝트에서 빠르게 결과를 볼 수 있습니다.

@SpringBootApplication
public class DemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}

처음에는 `@SpringBootApplication`이 애플리케이션 시작점이라는 것부터 기억하면 됩니다.

03

HTTP

클라이언트와 서버가 데이터를 주고받는 약속입니다. 웹 API에서는 주로 GET, POST, PUT, PATCH, DELETE 메서드를 사용합니다.

GET /students/1 HTTP/1.1
Host: example.com
Accept: application/json

URL은 자원, 메서드는 행동, 상태 코드는 결과라고 생각하면 쉽습니다.

04

REST API

자원을 URL로 표현하고 HTTP 메서드로 행동을 나타내는 API 설계 방식입니다.

@GetMapping("/students/{id}")
public StudentResponse findStudent(@PathVariable Long id) {
    return studentService.findById(id);
}

`/getStudent`보다 `/students/1`처럼 자원 중심으로 설계합니다.

05

MVC

Model, View, Controller로 역할을 나누는 구조입니다. API 서버에서는 View 대신 JSON 응답을 주는 경우가 많습니다.

@RestController
@RequestMapping("/api/students")
class StudentController {
    @GetMapping
    List<StudentResponse> findAll() {
        return studentService.findAll();
    }
}

Controller는 요청을 받는 입구이지, 모든 일을 처리하는 곳이 아닙니다.

06

IoC

Inversion of Control의 줄임말로, 객체 생성과 관리의 주도권을 개발자 코드가 아니라 Spring 컨테이너가 갖는다는 뜻입니다.

// 직접 생성
StudentService service = new StudentService();

// Spring이 생성하고 관리
@Service
class StudentService { }

IoC를 이해하면 왜 `new`를 덜 쓰는지 자연스럽게 보입니다.

07

DI

Dependency Injection은 필요한 객체를 외부에서 넣어주는 방식입니다. Spring에서는 생성자 주입을 기본으로 권장합니다.

@Service
class StudentService {
    private final StudentRepository repository;

    StudentService(StudentRepository repository) {
        this.repository = repository;
    }
}

필드 주입보다 생성자 주입이 테스트와 유지보수에 유리합니다.

08

Bean

Spring 컨테이너가 생성하고 관리하는 객체입니다. `@Component`, `@Service`, `@Repository`, `@Controller` 등이 Bean 등록에 사용됩니다.

@Configuration
class AppConfig {
    @Bean
    PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}

Bean은 “Spring이 관리하는 객체”라고 먼저 이해하면 충분합니다.

Part 2

핵심 구조

09

Controller

외부 요청을 받는 계층입니다. URL, HTTP 메서드, 요청 값을 해석하고 Service에 일을 맡깁니다.

@PostMapping("/students")
public StudentResponse create(@RequestBody StudentCreateRequest request) {
    return studentService.create(request);
}
10

Service

비즈니스 규칙을 처리하는 계층입니다. 예를 들어 “이미 존재하는 이메일은 가입 불가” 같은 규칙이 여기에 들어갑니다.

public StudentResponse create(StudentCreateRequest request) {
    if (repository.existsByEmail(request.email())) {
        throw new DuplicateEmailException();
    }
    return StudentResponse.from(repository.save(request.toEntity()));
}
11

Repository

데이터 저장소와 대화하는 계층입니다. Spring Data JPA를 쓰면 기본 CRUD 메서드를 자동으로 사용할 수 있습니다.

public interface StudentRepository
        extends JpaRepository<Student, Long> {
    boolean existsByEmail(String email);
}
12

DTO

Data Transfer Object는 요청과 응답에 사용하는 데이터 모양입니다. Entity를 그대로 노출하지 않기 위해 사용합니다.

public record StudentResponse(
    Long id,
    String name,
    String email
) {
    public static StudentResponse from(Student student) {
        return new StudentResponse(student.getId(), student.getName(), student.getEmail());
    }
}
13

Entity

DB 테이블과 연결되는 객체입니다. 식별자, 컬럼, 연관관계를 표현합니다.

@Entity
class Student {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String name;
    private String email;
}
14

JPA

자바 객체와 관계형 데이터베이스 테이블을 연결하는 표준 기술입니다. SQL을 직접 모두 쓰지 않아도 객체 중심으로 저장할 수 있습니다.

Student student = new Student("Kim", "kim@example.com");
studentRepository.save(student);
15

CRUD

Create, Read, Update, Delete의 줄임말입니다. 대부분의 웹 서비스 기본 기능은 이 네 가지에서 출발합니다.

@DeleteMapping("/students/{id}")
public void delete(@PathVariable Long id) {
    studentService.delete(id);
}
16

Validation

잘못된 입력을 초기에 막는 작업입니다. Bean Validation을 사용하면 DTO에 규칙을 선언할 수 있습니다.

public record StudentCreateRequest(
    @NotBlank String name,
    @Email String email
) { }
17

Exception

예외 처리는 실패 상황을 일관된 응답으로 바꾸는 작업입니다. API에서는 공통 에러 응답 형식을 정해두면 좋습니다.

@RestControllerAdvice
class GlobalExceptionHandler {
    @ExceptionHandler(DuplicateEmailException.class)
    ResponseEntity<ErrorResponse> handleDuplicate() {
        return ResponseEntity.status(409).body(new ErrorResponse("EMAIL_DUPLICATED"));
    }
}
18

Transaction

여러 DB 작업을 하나의 작업 단위로 묶습니다. 중간에 실패하면 전체를 되돌려 데이터 불일치를 막습니다.

@Transactional
public void enroll(Long studentId, Long courseId) {
    Student student = findStudent(studentId);
    Course course = findCourse(courseId);
    course.enroll(student);
}

Part 3

보안

19

Spring Security ⭐⭐⭐

인증과 인가를 처리하는 Spring 보안 프레임워크입니다. 로그인한 사용자인지, 특정 API를 사용할 권한이 있는지 확인합니다.

@Bean
SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
    return http
        .csrf(csrf -> csrf.disable())
        .authorizeHttpRequests(auth -> auth
            .requestMatchers("/api/admin/**").hasRole("ADMIN")
            .anyRequest().permitAll())
        .build();
}

보안은 마지막에 붙이는 기능이 아니라 API 설계와 함께 고려해야 하는 기본 구조입니다.

20

JWT ⭐⭐⭐

JSON Web Token은 로그인 결과를 토큰으로 표현하는 방식입니다. 서버는 토큰의 서명과 만료 시간을 확인해 사용자를 식별합니다.

String token = Jwts.builder()
    .subject(user.getId().toString())
    .claim("role", user.getRole())
    .expiration(expiration)
    .signWith(secretKey)
    .compact();

JWT에는 비밀번호 같은 민감한 정보를 넣지 않습니다.

21

Session vs JWT ⭐⭐

Session은 서버가 로그인 상태를 저장하고, JWT는 클라이언트가 토큰을 들고 다니는 방식에 가깝습니다.

Session서버 저장, 로그아웃 처리 쉬움
JWT확장성 좋음, 토큰 관리 중요

처음 프로젝트에서는 구조가 단순한 Session부터 이해한 뒤 JWT로 넘어가면 좋습니다.

Part 4

실무 개발

22

Gradle

빌드, 테스트, 의존성 관리를 담당합니다.

dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-web'
    testImplementation 'org.springframework.boot:spring-boot-starter-test'
}
23

application.yml

서버 포트, DB 연결, 로그 레벨 같은 애플리케이션 설정을 관리합니다.

spring:
  datasource:
    url: jdbc:h2:mem:testdb
server:
  port: 8080
24

Lombok

Getter, 생성자 등 반복 코드를 줄여줍니다. 팀 규칙에 맞춰 제한적으로 사용하는 것이 좋습니다.

@Getter
@NoArgsConstructor(access = AccessLevel.PROTECTED)
@Entity
class Student { }
25

SQL

DB에서 데이터를 조회하고 조작하는 언어입니다. JPA를 쓰더라도 SQL 기본기는 필요합니다.

SELECT id, name, email
FROM students
WHERE name LIKE 'Kim%';
26

Pagination

데이터를 한 번에 모두 보내지 않고 페이지 단위로 나눠 응답합니다.

@GetMapping
Page<StudentResponse> findAll(Pageable pageable) {
    return studentService.findAll(pageable);
}
27

Logging

프로그램 상태와 오류를 기록합니다. `System.out.println`보다 logger를 사용합니다.

private static final Logger log = LoggerFactory.getLogger(StudentService.class);
log.info("student created: {}", studentId);
28

Swagger

API 문서를 자동으로 확인하고 테스트할 수 있게 해줍니다.

implementation 'org.springdoc:springdoc-openapi-starter-webmvc-ui:2.8.9'
29

Git

코드 변경 이력을 관리합니다. 작은 단위로 커밋하고 메시지를 명확하게 남기는 습관이 중요합니다.

git add .
git commit -m "Add student CRUD API"
30

CORS

서로 다른 주소의 프론트엔드와 백엔드가 통신할 때 브라우저가 적용하는 보안 정책입니다.

@CrossOrigin(origins = "http://localhost:3000")
@RestController
class StudentController { }

Part 5

심화

31

AOP

여러 곳에 반복되는 부가 기능을 분리하는 방식입니다. 로깅, 권한 검사, 실행 시간 측정 등에 사용합니다.

@Around("@annotation(LogExecutionTime)")
public Object logTime(ProceedingJoinPoint joinPoint) throws Throwable {
    long start = System.currentTimeMillis();
    Object result = joinPoint.proceed();
    log.info("elapsed={}ms", System.currentTimeMillis() - start);
    return result;
}
32

Filter와 Interceptor

요청 전후에 공통 처리를 끼워 넣는 구조입니다. Filter는 Servlet 레벨, Interceptor는 Spring MVC 레벨에서 동작합니다.

@Override
public boolean preHandle(HttpServletRequest request,
                         HttpServletResponse response,
                         Object handler) {
    return true;
}
33

Redis

메모리 기반 저장소입니다. 캐시, 세션 저장, 랭킹, 인증 토큰 관리 등에 자주 사용됩니다.

@Cacheable(value = "students", key = "#id")
public StudentResponse findById(Long id) {
    return repository.findById(id).map(StudentResponse::from).orElseThrow();
}
34

Docker

애플리케이션과 실행 환경을 컨테이너로 묶습니다. 개발자마다 다른 환경 문제를 줄일 수 있습니다.

FROM eclipse-temurin:21-jre
COPY build/libs/app.jar app.jar
ENTRYPOINT ["java", "-jar", "/app.jar"]
35

CI/CD

코드가 올라올 때 자동으로 테스트, 빌드, 배포를 실행하는 흐름입니다.

name: build
on: [push]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          java-version: '21'
          distribution: 'temurin'
36

Spring AI

Spring 애플리케이션에서 LLM, 임베딩, 벡터 저장소 같은 AI 기능을 다루기 위한 프로젝트입니다.

@RestController
class ChatController {
    private final ChatClient chatClient;

    @GetMapping("/ai")
    String chat(String message) {
        return chatClient.prompt().user(message).call().content();
    }
}
