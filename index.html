Learning Flow

먼저 잡아야 할 흐름

1. 요청을 받는다

HTTP 요청은 Controller로 들어오고, URL과 메서드로 어떤 기능인지 구분합니다.

2. 규칙을 처리한다

Service는 가입 조건, 수정 가능 여부, 결제 정책 같은 애플리케이션 규칙을 담당합니다.

3. 데이터를 저장한다

Repository와 JPA는 Entity를 기준으로 DB와 데이터를 주고받습니다.

4. 운영 가능하게 만든다

보안, 검증, 예외, 로그, 문서화, 배포 설정이 있어야 수업 프로젝트가 실무형 프로젝트로 확장됩니다.
