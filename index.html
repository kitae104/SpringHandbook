Learning Flow

처음부터 읽을 때의 흐름

1. 요청을 이해한다

HTTP, REST API, MVC를 먼저 보면 URL, 메서드, 요청 본문, 응답 상태 코드가 어떻게 연결되는지 잡힙니다.

2. 계층을 나눈다

Controller, Service, Repository, DTO, Entity를 분리하면 API 코드가 커져도 책임이 섞이지 않습니다.

3. 상태와 실패를 다룬다

JPA, Transaction, Validation, Exception을 함께 보면 저장, 검증, 롤백, 오류 응답을 한 흐름으로 이해할 수 있습니다.

4. 운영 가능한 코드로 만든다

Spring Security, Logging, Swagger, Docker, CI/CD를 붙이면 개발용 예제가 실제 서비스에 가까운 구조로 확장됩니다.
