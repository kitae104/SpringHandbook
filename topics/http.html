HTTP

브라우저, 앱, 서버가 요청과 응답을 주고받기 위해 사용하는 웹 통신 약속입니다.

왜 배워야 할까

HTTP는 Spring Boot API의 입구입니다. URL은 어떤 자원을 다루는지, 메서드는 어떤 행동을 할지, 상태 코드는 결과가 어땠는지 알려줍니다.

처음에는 GET은 조회, POST는 생성, PUT/PATCH는 수정, DELETE는 삭제라는 식으로 익히면 됩니다. 요청 본문은 JSON으로 주고받는 경우가 많습니다.

관련 어노테이션과 기술

@GetMapping

GET 요청을 메서드에 연결합니다.

@PostMapping

POST 요청을 메서드에 연결합니다.

@RequestBody

요청 본문의 JSON을 자바 객체로 변환합니다.

@PathVariable

URL 경로의 값을 메서드 파라미터로 받습니다.

함께 확인하거나 수정할 부분

Controller

HTTP 요청을 가장 먼저 받는 계층입니다.

CORS

프론트엔드 주소와 백엔드 주소가 다르면 브라우저 정책을 확인해야 합니다.

Postman 또는 Swagger

요청 메서드, URL, 헤더, 본문을 직접 확인합니다.

HTTP 요청과 Controller 매핑

@RestController
@RequestMapping("/api/students")
class StudentController {
    @GetMapping("/{id}")
    StudentResponse find(@PathVariable Long id) {
        return studentService.find(id);
    }
}

처리할 때 주의할 점

  • 404는 URL 매핑 문제, 400은 요청 값 문제, 500은 서버 내부 오류인 경우가 많습니다.
  • GET 요청에 중요한 변경 작업을 넣지 않습니다.
