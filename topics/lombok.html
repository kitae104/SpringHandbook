Lombok

Getter, 생성자, Builder 같은 반복 코드를 어노테이션으로 줄여주는 도구입니다.

왜 배워야 할까

Lombok은 자바 코드의 반복을 줄여주지만, 생성되는 코드를 눈으로 직접 보지 않기 때문에 처음 배우는 학생에게는 오히려 흐름을 숨길 수 있습니다.

DTO에는 @Builder나 @Getter가 편리할 수 있고, Entity에는 @Data 사용을 피하고 필요한 어노테이션만 제한적으로 사용하는 것이 좋습니다.

관련 어노테이션과 기술

@Getter

필드 getter를 생성합니다.

@RequiredArgsConstructor

final 필드를 받는 생성자를 생성합니다.

@NoArgsConstructor

기본 생성자를 생성합니다.

@Builder

Builder 패턴 코드를 생성합니다.

@Data

Getter, Setter, equals, hashCode, toString을 모두 생성합니다.

함께 확인하거나 수정할 부분

IDE 플러그인

Lombok 어노테이션 처리가 IDE에서 활성화되어야 합니다.

Entity

@Data와 무분별한 @Setter는 Entity에서 조심합니다.

DI

@RequiredArgsConstructor로 생성자 주입 코드를 줄일 수 있습니다.

생성자 주입 코드 줄이기

@Service
@RequiredArgsConstructor
class StudentService {
    private final StudentRepository repository;
}

처리할 때 주의할 점

  • Lombok이 만든 코드를 이해하지 못하면 디버깅이 어려워집니다.
  • Entity의 toString이 연관 객체를 계속 호출하면 순환 참조 문제가 생길 수 있습니다.
