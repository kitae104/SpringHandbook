11 · Part 2. 핵심 구조

Repository

데이터베이스와의 조회, 저장, 삭제 작업을 담당하는 데이터 접근 계층입니다.

왜 배워야 할까

Repository는 애플리케이션이 DB와 직접 대화하는 통로입니다. Spring Data JPA를 사용하면 인터페이스만 작성해도 기본 CRUD 메서드가 제공됩니다.

메서드 이름으로 쿼리를 만들 수 있지만, 복잡한 조건이 늘어나면 @Query, QueryDSL, 명세 패턴 같은 방법을 검토합니다.

관련 어노테이션과 기술

@Repository

데이터 접근 계층 Bean을 나타냅니다.

@Query

직접 JPQL 또는 native SQL을 작성합니다.

@Param

@Query의 파라미터 이름을 연결합니다.

함께 확인하거나 수정할 부분

Entity

Repository는 보통 Entity 타입과 ID 타입을 기준으로 작성합니다.

JPA

JpaRepository를 상속하면 save, findById, delete 등이 제공됩니다.

SQL 로그

실행 SQL을 확인하려면 logging.level.org.hibernate.SQL 설정을 사용합니다.

Spring Data JPA Repository

public interface StudentRepository extends JpaRepository<Student, Long> {
    boolean existsByEmail(String email);

    @Query("select s from Student s where s.name like concat(:name, '%')")
    List<Student> findByNamePrefix(@Param("name") String name);
}

처리할 때 주의할 점

  • Repository에서 비즈니스 규칙을 처리하지 않습니다.
  • N+1 문제가 생기면 fetch join이나 EntityGraph를 검토합니다.
