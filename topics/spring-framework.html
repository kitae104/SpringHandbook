01 · Part 1. Spring 기초

Spring Framework

자바 애플리케이션에서 객체 생성, 의존성 연결, 웹 요청 처리, 데이터 접근을 체계적으로 도와주는 기반 프레임워크입니다.

왜 배워야 할까

Spring Framework는 큰 프로젝트에서 자바 객체를 직접 만들고 연결하는 코드를 줄이기 위해 등장했습니다. 학생들이 처음 헷갈리는 지점은 Spring이 단순한 라이브러리가 아니라 애플리케이션의 객체 흐름을 관리하는 컨테이너 역할을 한다는 점입니다.

Spring Boot를 배우더라도 Spring Framework의 핵심인 IoC, DI, Bean, AOP, MVC를 이해해야 합니다. Boot는 Spring을 쉽게 시작하게 해 주지만, 내부 동작은 Spring Framework 위에서 이루어집니다.

관련 어노테이션과 기술

@Component

Spring이 관리할 일반 컴포넌트를 등록합니다.

@Configuration

Bean 등록 메서드를 가진 설정 클래스를 나타냅니다.

@Bean

외부 라이브러리 객체처럼 직접 생성해야 하는 객체를 Spring Bean으로 등록합니다.

함께 확인하거나 수정할 부분

build.gradle

spring-boot-starter-web, spring-boot-starter-data-jpa 같은 starter 의존성을 확인합니다.

패키지 구조

메인 클래스 하위 패키지에 컴포넌트가 있어야 기본 컴포넌트 스캔 대상이 됩니다.

Spring이 관리하는 서비스 객체

@Component
public class GreetingService {
    public String greet(String name) {
        return "Hello, " + name;
    }
}

처리할 때 주의할 점

  • Spring이 객체를 관리하려면 Bean으로 등록되어야 합니다.
  • 무조건 @Component만 쓰기보다 역할에 맞게 @Service, @Repository, @Controller를 사용합니다.
